# pawfectchaos-post-images

Public media hosting for `@pawfectchaos1` posts (Instagram/Facebook), served via
`raw.githubusercontent.com`. Same pattern as `visual-versatility-post-images`.

Meta's Graph API fetches media by public URL — it can't read a private repo — so
files pushed here just need to exist at a stable path; nothing else reads this repo.

Populated by `pawfectchaos-bot` (the Telegram listener on HP) and by manual pushes.
